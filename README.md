**莫斯科机房延迟怎么自测？**
用 46.17.40.85 做 ping 和路由追踪，这是 2021 年第三方记录的莫斯科 DataLine 测试地址，只能作为参考。更准确的方式是买最短周期实测，VPS 月付门槛低，试错成本可控。

**能不能换机房、换 IP？**

**VPS 和独立服务器怎么分？**
按是否需要独享资源分。VPS 的 CPU 和带宽都是共享的，fair-share 端口在邻居跑满时会掉速；独立服务器给你整台机器、2 个 IPv4、可选 1Gbit 甚至 10Gbit 独享端口。日 PV 几千以内、没有持续高 IO 的项目，VPS 就够。

**首月退款能拿回多少？**
独立服务器扣掉 50% 安装费，500 美元的机器退 250 美元。VPS 按实际使用情况核算，需要提交申请并通过问题核查，14 天内处理，到账最长 45 天，赠送金额和域名费用不退。

**优惠码能叠加吗？**
官方活动页没有说明叠加规则，按一个码使用来算。
